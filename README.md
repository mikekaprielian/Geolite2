# Geolite2
Script that downloads the latest updates Geolite2 an be used for Xtream-UI or other products. 

First make sure to sign up to a free geolite2 account here

https://www.maxmind.com/en/geolite2/signup

Once you are logged in, you must click on "Manage License key" and Generate a new license key. Use that key in the script.
